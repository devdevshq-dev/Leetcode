# LeetCode Solutions

A collection of my solutions to **LeetCode problems**, written while practicing Data Structures & Algorithms and preparing for technical interviews.

The goal of this repository is to build strong problem-solving skills, understand different approaches, and maintain a structured record of solved problems.

## 📌 About

This repository contains solutions to LeetCode problems covering topics such as:

* Arrays
* Strings
* Hashing
* Two Pointers
* Sliding Window
* Binary Search
* Linked Lists
* Stacks & Queues
* Recursion & Backtracking
* Trees
* Binary Search Trees
* Graphs
* Dynamic Programming
* Greedy Algorithms
* Heaps / Priority Queues
* Bit Manipulation
* Sorting
* Math

Most solutions are written in **C++**.

## 🧠 Problem-Solving Approach

For each problem, I try to focus on:

1. Understanding the problem
2. Identifying the underlying pattern
3. Developing a brute-force solution
4. Optimizing the solution
5. Analyzing time and space complexity
6. Implementing a clean and efficient solution
